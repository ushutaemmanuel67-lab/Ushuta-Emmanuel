# Smashburger Website Project

A responsive, Smashburger-inspired restaurant website built with HTML and CSS only.

## Files
- `index.html` — page structure and content
- `style.css` — colors, layout, typography and responsive styles

## Run in VS Code
1. Extract `smashburger-school-project.zip`.
2. Open VS Code.
3. Select **File → Open Folder** and choose the extracted `smashburger-school-project` folder.
4. Open `index.html`.
5. Right-click inside the editor and choose **Open with Live Server** (if the Live Server extension is installed).
   - Or double-click `index.html` in File Explorer to open it in Chrome.

## Notes
- The layout adapts to desktop, tablet and mobile screens using CSS media queries. No JavaScript is required.
- Food photos are loaded from Unsplash, so an internet connection is needed to display them.
- This is an educational, unofficial recreation inspired by the reference screenshot. It is not affiliated with Smashburger.
